# Contributing

Thanks for helping investigate GTMedia GTX Combo support. Please keep findings scoped to **CoreELEC**. OpenATV/Enigma2 findings belong to its separate repository.

For each claim please provide the exact device model, board revision if known, build/kernel, observation date, **sanitized** console evidence, and confidence (operator-log, reported, inferred, untested). Avoid uploading vendor firmware, kernel binary modules, full dumps, captured broadcasts, credentials, serial numbers, or private account data. Do not imply a reported upstream issue proves a working fix.

Review the research scripts before making any device changes. Source patches and maintainable upstream contributions are preferred. No project-wide license is currently selected.
